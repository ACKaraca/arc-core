# Package compatibility fixtures

Packages written by released versions of `arc-doc`, opened by every later version (the
compatibility promise of [document-package.md](../../docs/architecture/document-package.md)).
Fixtures are never regenerated: a changed fixture is a broken promise. A new format version adds
new files beside these.

| File | Content |
|---|---|
| `v1-minimal.arc` | Format 1.0: one object of the fixture type `fx.point`, saved as a new document; metadata only, no previews (`thumbnail` = `none`) |
| `v1-typical.arc` | Format 1.0: two `fx.point` objects, an `fx.line` referring to them, an `fx.note` written at version 1.0 and migrated to 2.0 by the save, a preserved object of the unknown type `fx.legacy` 3.0, a quarantined `fx.point` with a corrupt payload, the derived indexes, a 256 × 256 thumbnail and a 1,024 × 8 preview |
| `newer-major.arc` | `v1-minimal.arc` with `user_version` 2 and `format_version` `2.0`: every current version refuses it without changing it or creating a lock |
| `v1-minimal.json`, `v1-typical.json` | The canonical dump of the decoded document the test compares with after opening the fixture with the current code |

The fixture types (`fx.point`, `fx.line`, `fx.note`) and the dump are defined in
`crates/arc-doc/tests/package_fixtures.rs`; the types are part of the fixtures and never change.
The files were generated by the ignored test `generate_fixtures` of that file, which writes only
missing files:

```text
cargo nextest run -p arc-doc --features package --run-ignored only generate_fixtures
```

`v1-typical.arc` is the full-rewrite save of a package whose rows were written directly (to place
the version 1.0 note, the unknown type and the corrupt row), so it is a file as this release saves
it. The preview images are white 1-bit grayscale PNG files generated by the test helpers, created
for these fixtures and licensed with the repository. The `.json` dumps may be updated in a reviewed
change when the dump format changes; the `.arc` files may not. Each package is 72 to 84 KiB: a
package of format 1.0 has at least 18 pages of 4,096 bytes (one per table and index).
